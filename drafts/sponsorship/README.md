# Πακέτο χορηγίας (ΑΝΕΝΕΡΓΟ προσχέδιο)

Κατάσταση: **ΑΝΕΝΕΡΓΟ** — τίποτα εδώ δεν είναι συνδεδεμένο με το ζωντανό site,
τα workflows ή το DNS. Καμία ενέργεια δεν ενεργοποιείται αυτόματα.

## Περιεχόμενα (6 αρχεία)
- `sponsor-slot.html` — το ίδιο το block θέσης χορηγού (βασισμένο στο
  `drafts/advertise.html`), έτοιμο να μπει σε μία σελίδα του site όταν δοθεί ΟΚ.
  Παραμένει ανενεργό/μη ενσωματωμένο εδώ.
- `campaign-config.json` — ρυθμίσεις μίας καμπάνιας. `"active": false` εξ ορισμού,
  με **υποχρεωτικό** πεδίο λήξης (`end_date`). Μηδενικό πρακτικό αποτέλεσμα αν
  δεν αντιγραφεί σε πραγματικό config του site.
- `validate_campaign.py` — μικρό, χωρίς δίκτυο CLI εργαλείο που διαβάζει
  το `campaign-config.json` και λέει αν **σήμερα** θα έπρεπε να είναι ΟΡΑΤΗ ή
  ΚΡΥΦΗ η θέση (ανενεργό/μελλοντικό/ενεργό/ληγμένο/άκυρη διεύθυνση — 5 σενάρια
  καλύπτονται με `--self-test`). **Πρόκειται για πληροφοριακό pre-check, όχι
  για αυτόματη ενεργοποίηση/λήξη στο πραγματικό site** — αυτό απαιτεί πάντα το
  χειροκίνητο βήμα deploy από το activation-and-reporting.md.
- `redirect-template.html` — στατική σελίδα ανακατεύθυνσης ανά καμπάνια
  (χωρίς JavaScript tracking, χωρίς Worker/KV/DB). Προορίζεται να μπει σε
  διαδρομή όπως `/s/<slug>/index.html` ώστε να εμφανίζεται ξεχωριστά στο
  υπάρχον Cloudflare HTTP Analytics ανά καμπάνια.
- `activation-and-reporting.md` — ενοποιημένο: βήματα ενεργοποίησης,
  rollback/απενεργοποίηση, και πρότυπο τελικής αναφοράς (χωρίς πλασματικά νούμερα).

## Μέτρηση — πραγματικά όρια (όχι υποσχέσεις)
- Η λύση βασίζεται στο **υπάρχον** Cloudflare HTTP Analytics (δωρεάν tier,
  επίπεδο domain), με ξεχωριστό στατικό path ανά καμπάνια. Δεν προστέθηκε
  Worker, KV, βάση δεδομένων ή νέα συνδρομή.
- Τα HTTP requests σε ένα path **δεν ισοδυναμούν** με μοναδικά ανθρώπινα κλικ:
  περιλαμβάνουν bots/crawlers, prefetch, επαναφορτώσεις. Δεν υπάρχει εδώ
  επαληθευμένη μέτρηση μοναδικού χρήστη.
- **Επιβεβαιωμένο (Τάσος, 11/11/2026)**: το υπάρχον Cloudflare HTTP Analytics
  απαντά επιτυχώς σε φίλτρα hostname+path+status. **Δεν έχει ακόμη δοκιμαστεί**
  ένας πραγματικός χορηγικός σύνδεσμος/path — αυτό παραμένει ανοιχτό σημείο,
  ελέγχεται μόνο μετά από έγκριση και πραγματική ενεργοποίηση σε live path.
- **Κανάλι επικοινωνίας επιβεβαιωμένο (Τάσος, 11/11/2026)**: ενεργή προώθηση
  του `info@epidomatatora.gr`, επαληθευμένος παραλήπτης, 3 καταγραφές
  "delivered" στο Cloudflare Email Routing μεταξύ 13/10 και 11/11/2026.
- Δεν υπόσχομαι μηδενικό λειτουργικό κόστος εγγυημένα· η παραδοχή είναι ότι
  η προσθήκη λίγων στατικών αρχείων HTML σε ήδη υπάρχον στατικό Cloudflare
  Pages deployment δεν προσθέτει κόστος πέρα από το τρέχον πλάνο — αυτό
  βασίζεται στη φύση του static hosting, όχι σε επιβεβαιωμένη τιμολόγηση
  λογαριασμού που δεν έχω πρόσβαση να δω.
